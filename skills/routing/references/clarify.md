# Vague request

1. Scope unclear: **ask first**; do not guess or widen it (R-001).
2. Call the Skill tool with `grilling`.
3. Business rules unclear: read the project's domain documents first; still vague: stop and ask.
4. When settled, write the scope to `docs/artifact/<YYYY-MM-DD-HHMM-name>/intent.md` (required, R-092). If a plan exists, its "files touched" column refines it (R-002).
5. Go back to the routing tables and place the now-clear request in its flow.
